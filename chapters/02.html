2장. 게임 창과 배경

게임 화면을 담을 창을 만들고 동굴 배경을 깝니다. 먼저 제목이 있는 빈 창을 띄운 뒤, 제공된 배경 그림으로 창 안을 채웁니다. 배경은 다음 장부터 플레이어와 벽돌을 올려놓을 바탕이 됩니다.

2-1 빈 게임 창 띄우기

그림을 화면에 표시하려면 그림을 담을 창이 먼저 필요합니다. 자바의 Swing은 창, 버튼, 글자 같은 화면 요소를 만드는 GUI 라이브러리입니다. 이 게임에서는 Swing의 JFrame으로 게임 창을 만듭니다.

1장에서 작성한 BubbleFrame은 실행 여부를 콘솔에서 확인하는 클래스였습니다. 이번에는 JFrame을 상속하도록 바꾸고, 생성자에서 창의 제목과 크기를 정합니다. main()의 콘솔 출력문도 지우고 게임 창을 생성하는 코드로 바꿉니다.

이클립스에서 src/bubble/game/BubbleFrame.java를 열고 수정합니다.

수정 파일src/bubble/game/BubbleFrame.java
1package bubble.game;2−public class BubbleFrame {3+import javax.swing.JFrame;4+5+public class BubbleFrame extends JFrame {6+7+ public BubbleFrame() {8+ setTitle("버블 게임");9+ setSize(1000, 640);10+ setLocationRelativeTo(null);11+ setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);12+ setVisible(true);13+ }1415 public static void main(String[] args) {− System.out.println("버블 게임 준비");16+ new BubbleFrame();17 }18}

JFrame은 제목 표시줄과 닫기 버튼이 있는 창입니다. BubbleFrame이 JFrame을 상속하면 setTitle()과 setSize() 같은 메서드로 창을 설정할 수 있습니다.

main()에서 new BubbleFrame()을 실행하면 생성자가 호출됩니다. 생성자는 창을 설정한 뒤 화면에 표시합니다. 각 설정은 작성한 순서대로 적용됩니다.

setTitle("버블 게임")은 제목 표시줄에 표시할 글자를 정합니다. setSize(1000, 640)은 창의 너비를 1000픽셀, 높이를 640픽셀로 지정합니다. 이 크기에는 제목 표시줄과 테두리도 포함되므로, 실제로 그림을 놓는 안쪽 영역은 조금 작습니다.

setLocationRelativeTo(null)은 창을 화면 가운데에 놓습니다. 창 크기를 정한 다음 호출해야 그 크기를 기준으로 가운데 위치를 계산합니다.

setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)은 닫기 버튼을 눌렀을 때 프로그램도 종료하도록 정합니다. 이 설정이 없으면 기본 동작은 창을 숨기는 것이어서 프로그램이 계속 실행될 수 있습니다.

마지막의 setVisible(true)가 창을 화면에 표시합니다. 앞에서 제목과 크기를 정했더라도 이 메서드를 호출하기 전에는 창이 보이지 않습니다.

파일을 저장하고 BubbleFrame.java를 마우스 오른쪽 버튼으로 누릅니다. Run As → Java Application을 선택하면 main()이 실행됩니다.

화면 가운데에 제목이 ‘버블 게임’인 빈 창이 나타납니다. 아직 그림을 넣지 않아 창 안은 회색으로 보입니다.

닫기 버튼을 눌러 프로그램을 종료합니다. 다음 절에서는 이 창 안에 동굴 배경을 넣습니다.

2-2 배경 그림 깔기

배경 그림은 게임의 무대이면서 플레이어와 벽돌을 담을 영역입니다. 그림을 표시하는 JLabel을 창의 바탕으로 지정하면, 뒤에서 같은 영역에 게임 요소를 추가할 수 있습니다.

Swing에서 레이블(label)은 글자나 그림을 표시하는 화면 요소입니다. JLabel로 레이블을 만들고, ImageIcon으로 읽은 그림을 레이블에 넣습니다. 이번에는 제공된 image/background.png를 사용합니다.

앞 절의 setSize(1000, 640)은 창 바깥 크기를 정했습니다. 이 방식으로는 제목 표시줄과 테두리 때문에 배경 그림에 필요한 안쪽 크기를 맞추기 어렵습니다. setSize()를 지우고, 배경 레이블의 크기를 기준으로 창 크기를 맞추는 pack()으로 바꿉니다.

같은 src/bubble/game/BubbleFrame.java를 수정합니다.

수정 파일src/bubble/game/BubbleFrame.java
1package bubble.game;23+import javax.swing.ImageIcon;4import javax.swing.JFrame;5+import javax.swing.JLabel;67public class BubbleFrame extends JFrame {89 public BubbleFrame() {10 setTitle("버블 게임");− setSize(1000, 640);11+ setContentPane(new JLabel(new ImageIcon("image/background.png")));12+ setLayout(null);13+ pack();14+ setResizable(false);15 setLocationRelativeTo(null);16 setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);17 setVisible(true);

new ImageIcon("image/background.png")는 배경 그림 파일을 읽습니다. 경로는 실행 작업 폴더를 기준으로 찾습니다. 이클립스의 기본 실행 설정에서는 bubble 프로젝트 폴더가 기준이므로, 1장에서 받은 image 폴더가 프로젝트 바로 아래에 있어야 합니다.

new JLabel(...)은 읽은 그림을 표시할 레이블을 만듭니다. 이어서 setContentPane(...)으로 이 레이블을 창의 콘텐츠 영역(content pane)으로 지정합니다. 콘텐츠 영역은 제목 표시줄과 테두리를 제외하고 화면 요소를 담는 안쪽 영역입니다. 앞으로 추가할 플레이어와 벽돌도 이 배경 레이블 위에 놓입니다.

setLayout(null)은 콘텐츠 영역의 자동 배치를 끕니다. Swing은 보통 레이아웃 관리자(layout manager)로 요소의 위치와 크기를 정합니다. 하지만 게임에서는 플레이어가 움직일 때마다 좌표를 직접 바꿔야 합니다. 그래서 요소마다 위치와 크기를 지정하는 절대 배치(absolute positioning)를 사용합니다. 실제 좌표 지정은 다음 장에서 시작합니다.

pack()은 창 안의 요소가 요구하는 크기에 맞춰 창 크기를 정합니다. 그림을 담은 JLabel은 기본적으로 그림 크기를 선호 크기로 사용합니다. 따라서 배경 레이블을 지정한 다음 pack()을 호출하면 배경 그림이 들어갈 공간에 맞춰 창이 만들어집니다. 그림을 창 크기에 맞게 늘리는 동작은 아닙니다.

앞 절의 setSize(1000, 640)과 달리, 여기서는 배경 그림의 크기가 안쪽 영역의 기준입니다. 1000×640 배경 그림을 담으면 제목 표시줄과 테두리가 더해져 창 바깥 크기는 그보다 커집니다.

setResizable(false)는 사용자가 창 크기를 바꾸지 못하게 합니다. 배경과 게임 요소를 정해진 좌표에 놓을 예정이므로 창 크기도 고정합니다. 그다음 setLocationRelativeTo(null)이 완성된 창 크기를 기준으로 화면 가운데에 놓습니다.

실행 흐름은 main()에서 BubbleFrame을 생성하는 것으로 시작합니다. 생성자는 제목을 정하고 배경 레이블을 깐 뒤, pack()으로 크기를 맞춥니다. 마지막에 setVisible(true)를 호출하면 배경이 있는 창이 나타납니다.

파일을 저장하고 앞 절과 같은 방법으로 실행합니다. 제목이 ‘버블 게임’인 창 안에 동굴 배경이 보입니다.

배경이 나타나지 않으면 프로젝트 바로 아래에 image/background.png가 있는지 확인합니다. 파일 이름과 경로가 코드에 적힌 내용과 같아야 합니다.

완성한 코드는 장별 보관 패키지인 ex02에 복사합니다. 다음 장에서는 src/bubble/game의 코드를 이어서 수정하며 배경 위에 플레이어를 놓습니다.
