10장. 적군 만들기

9장에서는 시간이 지난 물방울을 화면과 목록에서 지웠습니다. 이번 장에서는 적군 셋을 추가합니다. 적군은 키를 누르지 않아도 혼자 걷고, 양쪽 벽에 닿으면 방향을 바꿉니다. 발판을 벗어나면 플레이어처럼 바닥으로 떨어집니다.

장을 마치면 적군들이 바닥에서 걷습니다. 왼쪽 벽에 먼저 닿은 적군은 오른쪽으로 돌아섭니다.

10-1 적군 셋 세우기

적군의 그림과 목록 준비하기

적군도 플레이어처럼 JLabel에 그림 한 장을 담아 만듭니다. 위치와 바라보는 방향은 Enemy 클래스에서 관리합니다. 같은 클래스로 적군 셋을 만들되, 시작 위치를 다르게 지정합니다.

물방울을 bubbles에 모았듯 적군은 enemies에 모읍니다. 적군마다 별도의 필드를 만드는 대신 목록에 담습니다. 그러면 게임 루프에서 모든 적군을 차례로 움직일 수 있습니다.

새 파일: src/bubble/game/Enemy.java
수정 파일: src/bubble/game/BubbleFrame.java

Enemy.java를 만들고, BubbleFrame.java에 적군 목록과 적군을 추가하는 코드를 작성합니다. 적군을 만드는 코드는 발판을 배치하는 반복문 뒤, 키 리스너를 등록하는 코드 앞에 넣습니다.

시작 방향에 맞는 그림 고르기

Enemy의 생성자는 시작 좌표 x, y와 방향 direction을 받습니다. 전달받은 값을 필드에 저장하므로, 적군마다 자신의 위치와 방향을 기억합니다.

enemyR에는 image/enemyR.png를, enemyL에는 image/enemyL.png를 담습니다. 생성자에서 방향이 Direction.LEFT이면 왼쪽 그림을 고르고, 그 외에는 오른쪽 그림을 고릅니다.

setSize(50, 50)은 적군의 크기를 정합니다. setLocation(x, y)은 적군의 왼쪽 위 모서리를 지정한 좌표에 놓습니다. 플레이어와 마찬가지로, 필드에 좌표를 저장한 뒤 setLocation()으로 화면 위치에 반영합니다.

목록에 담은 적군을 창에 추가하기

BubbleFrame에서는 enemies에 적군 셋을 추가합니다. 시작 좌표는 각각 (500, 570), (880, 570), (700, 440)입니다. 세 적군 모두 Direction.LEFT를 전달하므로 처음에는 왼쪽을 봅니다.

앞의 두 적군은 바닥에 놓이고, 세 번째 적군은 오른쪽 아래 발판에 놓입니다. 적군의 높이가 50이므로 아래쪽 끝은 각각 620, 620, 490이 됩니다. 적군의 아래쪽 끝이 바닥과 발판의 윗면에 맞닿는 위치입니다.

enemies.add()는 목록에 적군을 기록하는 작업입니다. 목록에 담았다고 화면에 나타나지는 않습니다. 뒤의 반복문에서 add(enemy)를 호출해야 창에 적군이 표시됩니다.

실행 결과

이클립스에서 앞 장과 같은 방법으로 Run As → Java Application을 실행합니다. 바닥에 적군 둘, 오른쪽 아래 발판에 적군 하나가 나타납니다. 셋 모두 왼쪽을 보고 서 있습니다.

아직 게임 루프에서 적군의 위치를 바꾸지 않으므로, 기다려도 움직이지 않습니다.

10-2 적군이 혼자 걷고 벽에서 돌아서기

매 틱 이동과 낙하 연결하기

플레이어는 누르고 있는 키에 따라 움직입니다. 적군은 키 입력 대신 자신이 기억한 방향을 따라 움직이게 만듭니다. 게임 루프가 반복될 때마다 같은 방향으로 조금씩 이동하면 혼자 걷는 모습이 됩니다.

양쪽 벽에서는 이동을 멈추는 대신 방향을 바꿉니다. 발판 끝에서는 계속 걸어 나가도록 두고, 중력으로 아래로 떨어지게 합니다.

수정 파일: src/bubble/game/Enemy.java
수정 파일: src/bubble/game/BubbleFrame.java

Enemy.java에 이동 속도, 중력, 세로 속도를 추가합니다. 이어서 move()와 fall()을 작성합니다. BubbleFrame.java의 tick()에는 적군 목록을 도는 반복문을 넣습니다.

방향에 따라 가로 좌표 바꾸기

SPEED는 한 틱에 가로로 이동할 거리이며 값은 2입니다. move()는 direction이 Direction.LEFT이면 x에서 SPEED를 뺍니다. 오른쪽을 보고 있으면 더합니다.

플레이어와 달리 왼쪽 키나 오른쪽 키를 누르는지 확인하지 않습니다. move()를 호출할 때마다 기억한 방향으로 이동하므로, 키를 모두 떼고 있어도 걷습니다.

벽 안쪽으로 위치를 맞추고 돌아서기

가로로 이동한 다음에는 양쪽 경계를 확인합니다. 왼쪽 경계는 x = 40, 오른쪽 경계는 x = 910입니다. 앞 장에서 플레이어의 이동 범위를 제한한 좌표와 같습니다.

x < 40이면 적군이 왼쪽 경계를 넘어간 상태입니다. 이때 x를 40으로 맞추고 방향을 Direction.RIGHT로 바꿉니다. 다음 틱부터는 x가 증가하므로 오른쪽으로 걷습니다.

오른쪽도 같은 방식입니다. x > 910이면 x를 910으로 맞추고 방향을 Direction.LEFT로 바꿉니다. 좌표를 경계에 맞추기 때문에 적군이 벽 안으로 파고들지 않습니다.

이 코드는 벽돌 그림과 겹치는지 직접 검사하지 않습니다. 적군이 움직일 수 있는 x 범위를 정해 벽에 닿았는지 판단합니다. 조건이 <와 >이므로, 정확히 경계 좌표에 도착한 순간에는 방향을 유지합니다. 다음 이동에서 경계를 넘으려 할 때 돌아섭니다.

방향을 바꾼 뒤에는 setIcon()으로 그림도 다시 고릅니다. 왼쪽 벽에서 오른쪽으로 돌아섰다면 enemyR이 표시됩니다. 마지막의 setLocation(x, y)이 계산한 위치를 화면에 반영합니다.

발판을 벗어나면 중력으로 떨어지기

적군도 플레이어처럼 중력의 영향을 받습니다. GRAVITY는 매 틱 세로 속도에 더할 값이고, dy는 적군의 세로 속도입니다.

fall()은 먼저 bottom = y + 50으로 이동 전 아래쪽 끝을 기록합니다. 이어서 dy에 GRAVITY를 더하고, 그 속도만큼 y를 늘립니다. 화면에서는 y가 커질수록 아래로 내려갑니다. 착지하지 않고 떨어지는 동안에는 dy가 계속 커집니다.

바닥이나 발판에 착지했는지는 floors의 사각형으로 판단합니다. above는 적군의 아래쪽 끝이 발판 윗면에 도달하거나 윗면을 지났는지 확인합니다. 이동 전에는 발판 윗면보다 위에 있거나 같은 높이여야 합니다. 이동 후에는 발판 윗면에 도달하거나 지나야 합니다.

across는 적군과 발판의 가로 범위가 겹치는지 확인합니다. 위에서 내려왔더라도 가로로 벗어나 있으면 그 발판에 설 수 없습니다.

두 조건이 모두 참이면 y를 floor.y - 50으로 맞춥니다. 적군의 발이 발판 윗면에 놓이는 위치입니다. 이어서 dy = 0으로 세로 속도를 없앱니다.

발판에 서 있는 동안에도 매 틱 중력을 적용합니다. 적군이 조금 내려가려 하면 착지 조건이 성립하여 다시 발판 위에 놓입니다. 반대로 발판 끝을 완전히 벗어나면 가로 범위가 겹치지 않습니다. 그때부터는 아래로 떨어지다가 바닥에 착지합니다.

하나의 게임 루프에서 적군 모두 움직이기

tick()에 넣은 반복문은 enemies의 적군을 하나씩 꺼냅니다. 각 적군의 move()를 먼저 호출하고, 이어서 fall(floors)를 호출합니다.

한 틱의 적군 동작은 가로 이동에서 시작합니다. move() 안에서 벽을 확인하고 필요하면 방향을 바꿉니다. 벽에서 돌아섰는지와 관계없이, 그다음에는 fall(floors)로 낙하와 착지를 계산합니다.

이 순서 덕분에 발판 끝을 걸어 나간 틱에도 새 가로 위치를 기준으로 착지를 판단합니다. 더는 발판과 겹치지 않으면 바로 떨어지기 시작합니다.

적군을 움직이기 위해 새 Timer를 만들 필요는 없습니다. 기존 Timer가 호출하는 tick()에서 플레이어, 적군, 물방울을 차례로 움직입니다. 적군마다 위치와 속도를 따로 기억하므로, 같은 반복문 안에서도 각자의 자리에서 걷고 떨어집니다.

발판에서 떨어지고 벽에서 돌아서는지 확인하기

실행 결과

게임을 다시 실행하면 적군 셋이 왼쪽으로 걷습니다. 오른쪽 아래 발판에 있던 적군은 발판 끝을 벗어난 뒤 바닥으로 떨어집니다. 바닥에 착지한 뒤에도 왼쪽으로 계속 걷습니다.

잠시 기다리면 처음에 x = 500에서 출발한 적군이 왼쪽 벽에 먼저 도착합니다. 벽 앞에서 오른쪽 그림으로 바뀌고, 오른쪽으로 걷기 시작합니다. 이때는 적군 셋이 모두 바닥에 있습니다.

이번 장에서는 적군의 이동과 낙하만 만들었습니다. 플레이어나 물방울에 닿아도 아직 별도의 반응은 없습니다.
